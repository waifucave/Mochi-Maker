# Assets

Every image, model, project and sound in this repository is generated by this project's own code,
and is under the project's license ([MIT](LICENSE)). None is taken from another model, editor,
sample or website. No third-party art, models or sounds are committed.

| Asset | Where | Generated by |
|---|---|---|
| Golden projects (their art, meshes, rigs, motions and sounds) | `packages/export/test/golden/*.mochi` | `packages/export/test/golden.ts`, which draws each texture and builds each project with commands; `UPDATE_GOLDEN=1` rewrites them (`golden.test.ts`) |
| The conformance pack: exported models, scenarios, Mochi2D's results and reference renders | `conformance/` | `mochi-maker conformance-pack` from the golden projects; `UPDATE_PACK=1` rewrites it (`packages/export/test/conformance.test.ts`), with the renders by Mochi2D's renderer |
| The getting-started guide's example art, «Mochi» | `docs/guide/mochi.psd` | `packages/editor/test/guide-art.ts`, which draws the seven layers in code and writes the PSD with ag-psd |
| The guide's screenshots | `docs/guide/img/*.png` | `packages/editor/test/guide.test.ts`, which follows the guide in the editor and captures each step; `UPDATE_GUIDE=1` rewrites them |
| The README's own screenshots | `docs/img/*.png` | `packages/editor/test/guide.test.ts`, after the guide's last step (the Animation workspace with the sample's idle motion); `UPDATE_GUIDE=1` rewrites them. The README also shows two screenshots from `docs/guide/img/` |
| The sample model «Mochi»: model settings, `.moc3`, texture, display info, physics and an idle motion | `samples/mochi/` | `packages/mcp/test/guide.test.ts`, which builds the guide's model through the MCP tools, adds the idle motion and exports it; `UPDATE_GUIDE=1` rewrites it, and the test fails when the committed folder differs from the export |
| Sounds: golden 13's `voice.wav` (also in the pack) | `packages/export/test/golden/golden-13-sound.mochi/assets/`, `conformance/golden-13-sound/*/model/sounds/` | `squareWav` in `packages/export/test/golden.ts`, a one-second square wave |
| Sounds made during tests (vowels for motion sync, lip sync) | not committed | the tests themselves (`packages/export/test/motionsync.test.ts` and others) |
| The app icon: a white mochi on a green rounded square | `packages/editor/public/mochi-maker.svg` | written by hand for this project, as SVG source (no font, no third-party art, nothing traced). The editor uses it as its favicon; `packages/desktop/icons.mjs` rasterizes it into the desktop app's PNG, `.ico` and `.icns` at build time (not committed) |

Apart from that icon, the editor and the desktop app ship no image, icon or sound files: the editor
draws its interface with HTML, CSS and canvas code.
