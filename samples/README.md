# Sample models

## `mochi/` — «Mochi»

The getting-started guide's example model, as a model folder: `mochi.model3.json`, `mochi.moc3`
(version 5), its texture, display info, physics for the front hair and a three-second idle motion.
Its parameters use the usual IDs (`ParamAngleZ`, `ParamEyeLOpen`, `ParamEyeROpen`,
`ParamMouthOpenY`, `ParamHairFront`), and its settings name the EyeBlink and LipSync groups, so
apps can blink it and move its mouth. It uses neither glue nor blend shapes.

It is generated by this project's own code (`packages/mcp/test/guide.test.ts` builds the guide's
model, adds the idle motion and exports it; `UPDATE_GUIDE=1` rewrites this folder, and the test
fails when the folder differs from the export). The art is drawn in code
(`packages/editor/test/guide-art.ts`). Like the rest of the repository it is under the MIT License;
see [`ASSETS.md`](../ASSETS.md).

To build it yourself, follow [the guide](../docs/guide/README.md).
