# How Mochi Maker was written

Mochi Maker was written without Live2D Inc.'s software, and without other
apps' code, artwork or text.

- Its code was written by AI coding agents directed by the maintainer. They
  worked only from the project's own written briefs, Mochi2D's public API,
  documentation and source code, model data files, general programming
  knowledge and permissively licensed libraries.
- They did not view, install or run any Live2D SDK component, editor or
  manual, or any third-party implementation of the format. They did not open
  the editor's project formats, and they did not use Live2D Inc.'s sample
  models.
- Familiar layouts, terms and shortcuts follow descriptions of common
  conventions prepared for the project. The look, the icons and the names are
  Mochi Maker's own.
- The briefs and reports of this process are kept in a private record.
- Contributions follow the same rule: see CONTRIBUTING.md.
